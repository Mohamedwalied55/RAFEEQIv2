# رفيقي (RAFEEQI) — تطبيق إدارة الأدوية والرعاية الصحية

تطبيق عربي ذكي ومتكامل لإدارة مواعيد وجرعات الأدوية والمؤشرات الحيوية، مصمم خصيصاً للمرضى وكبار السن وأسرهم في العالم العربي، مع واجهتين منفصلتين بالكامل (واجهة مريض / واجهة مرافق) ونظام مزامنة سحابية لحظية عبر Firebase.

---

## المميزات الأساسية
- **فصل تام للأدوار:** تحديد دور الحساب لمرة واحدة عند التسجيل (`مريض` أو `مرافق`) مع توجيه مباشر لواجهة مخصصة.
- **تنبيهات ومنبّهات حقيقية على أندرويد:** تعمل حتى عند إغلاق التطبيق في الخلفية مع تكرار دوري وصوت منبّه مخصص.
- **مزامنة ثنائية ذكية:** سحب البيانات ودمجها تلقائياً، مع حماية الخصوصية ومنع الكتابة العشوائية وتخفيف حجم المستند السحابي.
- **ربط المريض والمرافق:** بكود ربط فريد وآمن (`RAF-XXXXXXXXXX`)، ومتابعة فورية للجرعات والقياسات وحالة المخزون.
- **مساعد طبي ذكي وفحص التداخلات:** عبر خادم Cloudflare Worker آمن للمستخدمين المسجلين.
- **تقارير صحية شاملة:** تصدير PDF احترافي مع دعم كامل للخط العربي Cairo وحماية صارمة من ثغرات XSS.

---

## متطلبات التشغيل
- Node.js (v18 أو أحدث)
- npm (v9 أو أحدث)
- أندرويد ستوديو وJDK 17+ (لبناء حزمة APK لنظام أندرويد)

---

## خطوات التثبيت والتشغيل المحلي

1. **تثبيت الاعتماديات:**
```bash
npm install
```

2. **تهيئة متغيرات البيئة:**
انسخ ملف الإعداد النموذجي:
```bash
cp .env.example .env.local
```
ثم افتح ملف `.env.local` وأدخل مفاتيح مشروعك في Firebase:
```env
# رابط خادم المساعد الذكي
VITE_API_BASE_URL="https://rafeeqi-ai.waliedm756.workers.dev"

# إعدادات Firebase (Auth & Firestore)
VITE_FIREBASE_API_KEY="your-api-key"
VITE_FIREBASE_AUTH_DOMAIN="rafeeqi-c8c57.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="rafeeqi-c8c57"
VITE_FIREBASE_STORAGE_BUCKET="rafeeqi-c8c57.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="your-sender-id"
VITE_FIREBASE_APP_ID="your-app-id"
```

3. **تشغيل خادم التطوير:**
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

---

## خطوات بناء حزمة أندرويد (APK)

1. **إضافة منصة أندرويد لأول مرة:**
```bash
npm run android:add
```

2. **إضافة صوت المنبّه (اختياري لكن موصى به):**
ضع ملف صوت المنبّه بصيغة `.wav` في المجلد `resources/alarm.wav`.

3. **المزامنة والتصحيح التلقائي للأذونات:**
```bash
npm run android:sync
```
يقوم هذا الأمر ببناء تطبيق الويب، ومزامنته مع Capacitor، وتشغيل `scripts/patch-android.mjs` لإضافة أذونات المنبّه والاهتزاز تلقائياً إلى `AndroidManifest.xml` ونسخ الصوت إلى مجلد `res/raw`.

4. **فتح المشروع في Android Studio:**
```bash
npx cap open android
```

## نشر وتطبيق قواعد أمان Firestore

قواعد الأمان المخصصة لحماية خصوصية بيانات المرضى والمرافقين موجودة في `firestore.rules`.
لتطبيقها على مشروع Firebase الخاص بك:
```bash
firebase deploy --only firestore:rules
```

## الأمان والخصوصية
- لا يمكن لأي مستخدم الوصول لسجلات مستخدم آخر إلا بإذن ربط صريح بالكود.
- الحسابات الزائرة (`guest_local`) تحفظ بياناتها محلياً فقط على الجهاز ولا تُرفع للسحابة.
- المساعد الذكي محمي ولا يستقبل طلبات إلا من مستخدمين موثقين مسجلين.
